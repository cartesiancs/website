# 문제 해결과 FAQ

## 자주 겪는 문제

### 클립이 미리보기에 보이지 않아요

- **위쪽 트랙의 클립이 가리고 있지 않나요?** 맨 위 트랙이 가장 앞에 보입니다. 눈 버튼으로 트랙을 하나씩 숨겨 보면 알 수 있습니다.
- **트랙이 숨겨져 있지 않나요?** 눈 버튼이 꺼진 트랙은 미리보기와 내보낸 영상 모두에서 보이지 않습니다.
- **끝선을 넘지 않았나요?** 빨간 선 오른쪽의 클립은 프로젝트 밖에 있습니다. [프로젝트 설정](project-settings)에서 **영상 길이**를 늘리세요.
- **화면 밖에 있지 않나요?** **위치**와 **Size**를 확인하세요. 해상도가 다른 프로젝트에 넣은 영상은 일부가 화면 밖에 있을 수 있습니다.

### 내보낸 영상이 너무 길거나 짧고, 끝이 검은 화면이에요

내보낸 영상은 항상 **설정 ▸ Canvas ▸ 영상 길이**와 정확히 같은 길이입니다. 편집 길이에 맞게 설정하세요.

### "미디어 파일을 찾을 수 없다"는 메시지가 나와요

프로젝트에 넣은 뒤 미디어 파일을 옮기거나, 이름을 바꾸거나, 지운 경우입니다. 파일을 원래 위치로 되돌려 주세요. 다음부터는 미디어를 `.ngt` 파일과 같은 폴더에 두면 폴더째로 옮길 수 있습니다. [저장과 자동 저장](saving-and-autosave#미디어-파일은-어디에-있나요)을 참고하세요.

### 재생이 끊겨요

4K, 높은 프레임 레이트, 레티나 화면 녹화처럼 무거운 영상은 실시간으로 재생하기 버거울 수 있습니다. **유틸리티 ▸ Proxy Media**로 프록시를 만드세요. 내보내기에는 여전히 원본이 사용됩니다. [Proxy Media](utilities#proxy-media)를 참고하세요.

### 타임라인이 편집되지 않아요

자동 자막 패널이 열려 있으면 **Apply**를 누르거나 패널을 닫을 때까지 타임라인이 잠깁니다. 이때 트랙 메뉴에 자물쇠가 표시됩니다.

단축키가 아무 반응이 없다면 미리보기 도구 모음의 **자물쇠**(**Lock keyboard shortcuts**)가 켜져 있지 않은지 확인하세요.

### On-device 자막이 흐리게 표시돼요

Mac에서 직접 받아쓰려면 macOS 26 이상이 필요합니다. 그 이전 버전에서는 ⚡ 패널의 **OpenAI API** 탭에 OpenAI API 키를 넣고 **OpenAI**를 사용하세요. [자동 자막](auto-captions)을 참고하세요.

### 화면 녹화가 검게 나오거나 Start Recording이 흐려요

CartCut에 화면 기록 권한이 없는 상태입니다. **시스템 설정 ▸ 개인정보 보호 및 보안**에서 권한을 켜고 CartCut을 다시 실행하세요. [화면 녹화](screen-recording#권한)를 참고하세요.

### 넣은 텍스트가 보이지 않아요

텍스트 트랙이 영상 트랙보다 **위에** 있는지 확인하세요. 트랙의 **⋮ ▸ Move up**으로 올릴 수 있습니다.

### 내보내기가 실패해요

오류 메시지를 확인하세요. FFmpeg가 언급되어 있다면 **About ▸ Setting ▸ Reinstall FFmpeg**를 실행하세요. 다른 내보내기가 진행 중이라면 끝날 때까지 기다리세요.

### 저장하지 않은 작업을 잃어버렸어요

**File ▸ Auto Save**를 열어 보세요. 복구 지점이 있다면 선택하면 됩니다. [저장하지 않은 작업 복구하기](saving-and-autosave#저장하지-않은-작업-복구하기)를 참고하세요.

## 자주 묻는 질문

### CartCut은 정말 무료인가요?

네. 구독료, 워터마크, 계정이 모두 없습니다. CartCut은 MIT 라이선스로 공개된 오픈소스입니다.

### Windows나 Linux에서도 쓸 수 있나요?

지금은 macOS용 설치 파일만 배포됩니다. Windows와 Linux에서는 소스 코드로 직접 빌드할 수 있습니다. [저장소](https://github.com/cartesiancs/cartcut)를 참고하세요.

### 내 영상이 어딘가로 업로드되나요?

아니요. 편집, 내보내기, Mac 안에서 하는 자막 받아쓰기는 모두 내 Mac에서 이루어집니다. OpenAI 받아쓰기를 고르거나, AI 어시스턴트를 연결해 프로젝트 작업을 요청할 때만 미디어 정보가 컴퓨터 밖으로 나갑니다.

### 다른 Mac에서 프로젝트를 열 수 있나요?

네. `.ngt` 파일과 그 안의 미디어를 포함한 프로젝트 폴더를 통째로 복사해서 열면 됩니다. 프로젝트에 쓴 템플릿과 확장 프로그램은 그 Mac에도 설치되어 있어야 합니다.

### 프레임 레이트는 얼마로 해야 하나요?

가능하면 촬영한 영상과 맞추세요. 영화 같은 느낌은 24나 25, 스마트폰과 웹 영상은 대부분 30, 부드러운 움직임과 화면 녹화는 60이 좋습니다.

### 버그 제보나 기능 제안은 어디에 하나요?

[GitHub](https://github.com/cartesiancs/cartcut/issues)에 이슈를 남기거나, CartCut 창 오른쪽 아래의 **?** 버튼을 누르고 **Report Bug**를 선택하세요. 버그 제보, 기능 제안, 풀 리퀘스트 모두 환영합니다.
