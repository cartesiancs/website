# 단축키

CartCut의 모든 단축키를 작업별로 정리했습니다. 앱 안에서는 언제든 <kbd>⌘</kbd> <kbd>/</kbd>를 눌러 이 목록을 볼 수 있습니다.

> [!NOTE]
> Windows에서 빌드한 경우 이 페이지의 <kbd>⌘</kbd>를 <kbd>Ctrl</kbd>로 바꿔 사용하세요.

## 편집

| 단축키 | 동작 |
| --- | --- |
| <kbd>⌘</kbd> <kbd>Z</kbd> | 실행 취소 |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | 다시 실행 |
| <kbd>⌘</kbd> <kbd>X</kbd> | 선택한 클립 잘라내기 |
| <kbd>⌘</kbd> <kbd>C</kbd> | 선택한 클립 복사 |
| <kbd>⌘</kbd> <kbd>V</kbd> | 재생 헤드 위치에 붙여넣기 |
| <kbd>⌘</kbd> <kbd>D</kbd> | 선택한 클립을 재생 헤드에서 자르기 |
| <kbd>Delete</kbd> | 선택한 클립 삭제 |
| <kbd>⌘</kbd> <kbd>A</kbd> | 모든 클립 선택 |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd> | 선택 해제 |

입력란에 커서가 있을 때는 같은 키가 클립 대신 글자를 편집합니다.

## 프로젝트

| 단축키 | 동작 |
| --- | --- |
| <kbd>⌘</kbd> <kbd>S</kbd> | 저장 |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | 다른 이름으로 저장 |
| <kbd>⌘</kbd> <kbd>O</kbd> | 프로젝트 열기 |
| <kbd>⌘</kbd> <kbd>I</kbd> | 재생 헤드 위치에 미디어 가져오기 |
| <kbd>⌘</kbd> <kbd>E</kbd> | 영상 내보내기 |

## 재생

| 단축키 | 동작 |
| --- | --- |
| <kbd>Space</kbd> | 재생 / 정지 |
| <kbd>→</kbd> | 다음 프레임 |
| <kbd>←</kbd> | 이전 프레임 |

## 정렬

| 단축키 | 동작 |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 선택한 클립을 한 트랙 위 / 아래로 이동 |
| <kbd>⌘</kbd> <kbd>G</kbd> | 그룹으로 묶기 |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>G</kbd> | 그룹 해제 |
| <kbd>Esc</kbd> | 진행 중인 드래그 취소 |

## 미리보기

| 단축키 | 동작 |
| --- | --- |
| <kbd>⌘</kbd> <kbd>0</kbd> | 미리보기를 창에 맞추기 |
| <kbd>⌘</kbd> <kbd>+</kbd> | 확대 |
| <kbd>⌘</kbd> <kbd>-</kbd> | 축소 |

## 마우스와 트랙패드

| 동작 | 위치 | 결과 |
| --- | --- | --- |
| <kbd>Shift</kbd> + 클릭 | 타임라인 | 선택에 클립 추가 |
| 빈 곳에서 드래그 | 타임라인 | 사각형 안의 클립 선택 |
| 길게 누르기 또는 <kbd>Option</kbd> + 드래그 | 타임라인 클립 | 다른 트랙으로 이동 |
| <kbd>Option</kbd> + 클릭 | 볼륨 선 | 볼륨 점 추가/삭제 |
| 핀치 또는 <kbd>Ctrl</kbd> + 스크롤 | 타임라인, 미리보기 | 확대/축소 |
| <kbd>Shift</kbd> + 핸들 드래그 | 미리보기 | 비율 고정/해제 |
| <kbd>Option</kbd> + 키프레임 드래그 | 곡선 편집기 | 재생 헤드에 달라붙지 않게 이동 |

## 마스크 펜

펜으로 마스크를 그리는 동안:

| 단축키 | 동작 |
| --- | --- |
| <kbd>Return</kbd> | 모양 닫기 |
| <kbd>Delete</kbd> | 마지막 점 지우기 |
| <kbd>Esc</kbd> | 마스크 버리기 |

## 크롭

| 단축키 | 동작 |
| --- | --- |
| <kbd>Return</kbd> | 크롭 적용 |
| <kbd>Esc</kbd> | 취소 |

## 자막 편집

[자동 자막](auto-captions) 패널의 자막 줄 안에서:

| 단축키 | 동작 |
| --- | --- |
| <kbd>Return</kbd> | 커서 위치에서 줄 나누기 |
| 줄 맨 앞에서 <kbd>Delete</kbd> | 윗줄과 합치기 |
| 줄 맨 끝에서 <kbd>Fn</kbd> <kbd>Delete</kbd> | 아랫줄과 합치기 |
| <kbd>⌘</kbd> <kbd>Z</kbd> | 나누기/합치기 되돌리기 |
| <kbd>⌘</kbd> <kbd>Return</kbd> | 받아쓰기 시작(클립 선택 화면에서) |

## 단축키 끄기

미리보기 도구 모음의 **자물쇠**(**Lock keyboard shortcuts**)를 누르면 CartCut이 키 입력에 반응하지 않습니다. 다시 누르면 켜집니다.
