# 저장과 자동 저장

CartCut 프로젝트는 하나의 `.ngt` 파일로 저장됩니다. 이 페이지에서는 프로젝트를 저장하고 여는 방법, CartCut이 미디어 파일을 찾는 방식, 그리고 저장하지 않은 작업을 지켜 주는 자동 저장을 설명합니다.

## 프로젝트 저장하기

1. <kbd>⌘</kbd> <kbd>S</kbd>를 누르거나 **File ▸ Save Project**를 선택합니다.
2. 처음 저장할 때는 이름과 저장할 폴더를 정하고 **Save**를 누릅니다.
3. **Saved** 메시지가 나타나고, 창 제목에 파일 경로가 표시됩니다.

그다음부터는 <kbd>⌘</kbd> <kbd>S</kbd>를 누르면 묻지 않고 같은 파일에 저장합니다.

다른 이름으로 사본을 저장하려면 **File ▸ Save Project As…**(<kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd>)를 사용하세요.

## 프로젝트 열기

1. <kbd>⌘</kbd> <kbd>O</kbd>를 누르거나 **File ▸ Open Project…** 메뉴를 선택합니다.
2. `.ngt` 파일을 고릅니다.

지금 열려 있는 프로젝트에 저장하지 않은 변경 사항이 있으면 먼저 저장하라고 안내합니다. 실수로 작업을 잃지 않도록 하기 위해서입니다.

## 미디어 파일은 어디에 있나요

`.ngt` 파일에는 편집 내용만 저장되고 영상 파일 자체는 들어가지 않습니다. 대신 각 파일이 컴퓨터의 어디에 있는지를 기억합니다.

- 프로젝트에 넣은 뒤에는 **미디어 파일을 옮기거나 이름을 바꾸지 마세요.** 그렇게 하면 프로젝트를 열 때 *N개의 미디어 파일을 찾을 수 없다*는 메시지가 나타납니다.
- **미디어를 `.ngt` 파일과 같은 폴더(또는 그 안의 하위 폴더)에 두세요.** 그러면 CartCut이 프로젝트 기준의 상대 위치도 함께 기억하므로, 폴더 전체를 다른 Mac으로 옮기거나 복사해도 그대로 열립니다.

> [!TIP]
> 영상 하나당 폴더 하나를 만들고, 그 안에 `.ngt` 파일과 모든 클립을 넣은 `media` 폴더를 두면 깔끔하게 관리할 수 있습니다.

## 자동 저장

자동 저장은 CartCut이나 Mac이 예기치 않게 멈췄을 때를 대비해, 저장하지 않은 작업의 복구용 사본을 조용히 남겨 둡니다.

- 편집을 멈추고 약 5초가 지나면 기록하고, 계속 편집하는 동안에도 최소 1분에 한 번은 기록합니다.
- 프로젝트마다 복구 지점을 하나만 유지합니다. 기록이 쌓이지는 않습니다.
- <kbd>⌘</kbd> <kbd>S</kbd>로 저장하면 더 이상 필요 없으므로 그 프로젝트의 복구 지점은 삭제됩니다.
- 아무도 쓰지 않은 복구 지점은 14일 뒤에 정리됩니다.

자동 저장은 절대 `.ngt` 파일을 덮어쓰지 않습니다. `.ngt` 파일은 <kbd>⌘</kbd> <kbd>S</kbd>로만 저장됩니다.

### 저장하지 않은 작업 복구하기

1. CartCut을 실행합니다. 빈 프로젝트로 시작하는데, 복구는 바로 이 상태에서 해야 합니다.
2. **File ▸ Auto Save** 메뉴를 엽니다. 프로젝트 이름과 기록된 시각이 최신순으로 표시됩니다.
3. 복구할 항목을 고릅니다.
4. 편집 내용이 복원되고, 언제 기록된 사본인지 알려 주는 메시지가 나타납니다. 창 제목에는 **Recovered**와 **unsaved**가 표시됩니다.
5. <kbd>⌘</kbd> <kbd>S</kbd>를 누릅니다. 새 저장 위치를 묻기 때문에, 원래 파일은 직접 결정할 때까지 그대로 남아 있습니다.

**Auto Save** 메뉴가 흐리게 표시된다면 복구할 것이 없다는 뜻입니다. 모든 작업이 저장되어 있습니다.

> [!NOTE]
> 복구는 타임라인 전체를 바꾸기 때문에 비어 있고 저장된 상태의 프로젝트에서만 실행됩니다. 다른 편집이 열려 있다면 먼저 저장하세요.

## 종료하기

저장하지 않은 변경 사항이 있는 채로 종료하면 정말 종료할지 묻습니다. **No**를 누르면 돌아가서 저장할 수 있습니다.
