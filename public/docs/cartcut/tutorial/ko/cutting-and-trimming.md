# 자르기와 다듬기

편집의 대부분은 자르기입니다. 필요 없는 부분을 덜어 내고 남은 부분을 순서대로 놓는 일이죠. 이 페이지에서 그 모든 방법을 설명합니다.

## 클립 자르기(분할)

재생 헤드 위치에서 클립 하나를 둘로 나눕니다.

1. 클립을 클릭해 선택합니다.
2. 자를 위치로 재생 헤드를 옮깁니다.
3. <kbd>⌘</kbd> <kbd>D</kbd>를 누르거나, 도구 모음의 **Split at playhead**를 누르거나, **Clip ▸ Split at Playhead**를 선택합니다.

**선택된** 클립만 잘립니다. 여러 트랙을 같은 지점에서 자르려면 먼저 해당 클립들을 모두 선택하세요(예: <kbd>Shift</kbd> + 클릭).

## 클립 다듬기(트림)

클립이 시작하거나 끝나는 지점을 바꿉니다.

1. 클립의 왼쪽이나 오른쪽 끝에 마우스를 올려 포인터 모양이 바뀌는 것을 확인합니다.
2. 끝을 드래그합니다.

영상과 오디오 클립은 원본 파일의 처음이나 끝을 넘어서 늘릴 수 없고, 옆 클립에 닿으면 멈춥니다.

## 클립 옮기기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 앞뒤로 옮기기 | 클립 가운데를 좌우로 드래그 |
| 다른 트랙으로 옮기기 | 클립을 잠깐 누르고 있다가(또는 <kbd>Option</kbd>을 누른 채) 위아래로 드래그 |
| 한 트랙 위/아래로 옮기기 | <kbd>↑</kbd> 또는 <kbd>↓</kbd> |
| 드래그 취소 | 드래그하는 중에 <kbd>Esc</kbd> |

클립은 같은 종류의 트랙으로만 옮길 수 있고, 다른 클립과 겹치는 위치로는 옮겨지지 않습니다. 실수로 다른 클립을 덮는 일이 없습니다.

## 클립 지우기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 지우고 빈 자리 남기기 | 선택한 뒤 <kbd>Delete</kbd>, 또는 오른쪽 클릭 ▸ **Remove** |
| 지우고 빈 자리 메우기 | 오른쪽 클릭 ▸ **Remove and close gap**. 같은 트랙의 뒤쪽 클립이 왼쪽으로 당겨집니다 |

## 복사, 잘라내기, 붙여넣기

| 동작 | 단축키 |
| --- | --- |
| 복사 | <kbd>⌘</kbd> <kbd>C</kbd> |
| 잘라내기 | <kbd>⌘</kbd> <kbd>X</kbd> |
| 붙여넣기 | <kbd>⌘</kbd> <kbd>V</kbd> |

붙여넣은 클립은 재생 헤드 위치에 놓이고, 클립 사이의 간격을 유지하며, 자리가 있으면 원래 트랙으로 들어갑니다. 클립을 복제하려면 복사한 뒤 재생 헤드를 옮기고 붙여넣으세요.

## 클립 합치기

잘랐던 클립을 다시 붙이고 싶다면 이웃한 두 조각을 선택하고 도구 모음의 **Merge clips**(또는 **Clip ▸ Merge Clips**)를 누릅니다. 같은 클립에서 나온 조각끼리만 합칠 수 있습니다.

## 실행 취소와 다시 실행

| 동작 | 단축키 |
| --- | --- |
| 실행 취소 | <kbd>⌘</kbd> <kbd>Z</kbd> |
| 다시 실행 | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> |

드래그 한 번, 여러 클립 붙여넣기 한 번, 여러 트랙 자르기 한 번이 각각 한 단계로 기록되어 한 번에 되돌릴 수 있습니다.

> [!TIP]
> 긴 인터뷰를 손으로 자르고 있나요? [자동 자막](auto-captions)이 말이 없는 구간을 찾아 대신 잘라 줍니다.
