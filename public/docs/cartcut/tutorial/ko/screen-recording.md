# 화면 녹화

CartCut의 화면 녹화기는 화면 전체나 창 하나를 녹화하고, 원한다면 카메라와 마이크도 함께 담아 결과를 바로 타임라인에 올려 줍니다. **Auto Zoom**을 켜 두면 클릭한 곳을 자동으로 부드럽게 확대해 주어, 따로 편집하지 않아도 강의나 시연 영상을 보기 좋게 만들 수 있습니다.

## 녹화기 열기

1. **유틸리티**(슬라이더 아이콘)를 열고 **Screen Recorder**를 누릅니다.
2. 화면 맨 위 macOS 메뉴 막대에 **CartCut Recorder** 아이콘이 나타납니다. 녹화기의 모든 기능은 이 아이콘의 메뉴에 있습니다.

## 녹화 준비하기

메뉴 막대의 녹화기 아이콘을 누르면 다음 옵션이 나타납니다.

| 메뉴 | 선택 항목 |
| --- | --- |
| **Screen** | 각 화면(디스플레이), 그다음 열려 있는 각 창. 녹화할 대상을 고릅니다 |
| **Camera** | **None** 또는 버블로 보여 줄 카메라 |
| **Microphone** | **None** 또는 목소리를 녹음할 마이크 |
| **System Audio** | 컴퓨터 자체의 소리를 녹음합니다. Windows에서만 사용할 수 있습니다 |
| **Bubble** | 카메라 버블의 크기(Small, Medium, Large), 위치(네 모서리), 모양(Circle, Rounded Rectangle) |
| **Quality** | 720p, 1080p, Native(가장 선명); 15, 30, 60fps |
| **Auto Zoom** | On(기본값) 또는 Off |
| **Drawing Mode** | 녹화하면서 화면에 그림을 그릴 수 있습니다 |
| **Open Recordings Folder** | 녹화 파일이 저장된 폴더 열기 |
| **Close Recorder** | 메뉴 막대에서 녹화기 닫기 |

기본값은 Native 화질, 30fps, Auto Zoom 켜짐, 카메라와 마이크 없음입니다.

## 녹화하기

1. **Start Recording**을 선택합니다. 3, 2, 1 카운트다운이 끝나면 녹화가 시작됩니다.
2. 보여 주고 싶은 동작을 합니다. 평소처럼 클릭하면 되고, Auto Zoom이 켜져 있으면 클릭할 때마다 확대가 만들어집니다.
3. 녹화 중에는 메뉴에 **Pause** / **Resume**, **Stop Recording**, **Discard Recording**이 나타납니다.
4. **Stop Recording**을 선택합니다.

### 화면에 그리기

녹화기 메뉴에서 **Drawing Mode**를 켜면 설명하면서 화면 위에 그림을 그릴 수 있습니다. 도구 모음에서 펜 색과 **Erase**(지우기)를 고를 수 있고, **Done**을 누르거나 <kbd>Esc</kbd>를 누르거나 메뉴에서 Drawing Mode를 끄면 그리기가 끝납니다. 그린 내용도 영상에 녹화됩니다.

## 녹화를 마친 뒤

편집기에 진행 창이 나타나 파일 마무리, 포인터 이동 분석, 확대 계획, 타임라인에 추가하는 단계를 보여 줍니다. **Skip the zoom**을 누르면 확대 없이 녹화 영상만 넣습니다.

끝나면 녹화 영상이 **재생 헤드** 위치에 프로젝트 화면 크기에 맞춰 놓이고, 몇 번 확대했는지 알려 줍니다.

- 확대는 클립의 일반 **Size**, **위치** 키프레임으로 들어가므로, 각각 고치거나 지울 수 있습니다. [키프레임 애니메이션](keyframes)을 참고하세요.
- 카메라 버블과 그린 내용은 화면에, 마이크 소리는 클립의 소리에 포함됩니다.
- 파일은 홈 폴더의 **동영상(Movies) ▸ Cartcut Recordings**에 저장됩니다.

## 권한

처음 녹화할 때 macOS가 CartCut의 화면 기록을 허용할지 묻습니다.

1. **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 화면 및 시스템 오디오 기록**(이전 macOS에서는 **화면 기록**)을 엽니다.
2. **CartCut**을 켭니다.
3. CartCut을 종료했다가 다시 실행합니다.

**Start Recording**이 흐리게 표시되고 *No screen is available to capture*라고 나오거나 녹화 화면이 검게 나온다면 이 권한이 없는 것입니다. 카메라와 마이크 권한은 처음 고를 때 요청됩니다.

> [!NOTE]
> Auto Zoom의 클릭 감지는 macOS에서 동작합니다. CartCut은 언제 어디를 클릭했는지만 기록하며, 키보드로 무엇을 입력했는지는 절대 기록하지 않습니다.

## 간단한 녹화기

**유틸리티 ▸ Record**는 예전부터 있던 간단한 녹화기로, 미리보기 위에 탭으로 열립니다. 화면을 고르고 **record**, **stop**을 누르면 됩니다. 확대, 카메라, 그리기 기능은 없으며, 결과는 재생 헤드 위치에 놓입니다.
