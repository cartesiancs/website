# Keyboard shortcuts

Every shortcut in CartCut, grouped by task. Inside the app, press <kbd>⌘</kbd> <kbd>/</kbd> to see this list at any time.

> [!NOTE]
> On Windows builds, use <kbd>Ctrl</kbd> wherever this page shows <kbd>⌘</kbd>.

## Editing

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> | Redo |
| <kbd>⌘</kbd> <kbd>X</kbd> | Cut selected clips |
| <kbd>⌘</kbd> <kbd>C</kbd> | Copy selected clips |
| <kbd>⌘</kbd> <kbd>V</kbd> | Paste at the playhead |
| <kbd>⌘</kbd> <kbd>D</kbd> | Split the selected clips at the playhead |
| <kbd>Delete</kbd> | Remove selected clips |
| <kbd>⌘</kbd> <kbd>A</kbd> | Select all clips |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>A</kbd> | Deselect all |

When the cursor is in a text box, the same keys edit the text instead of clips.

## Project

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>S</kbd> | Save |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | Save as |
| <kbd>⌘</kbd> <kbd>O</kbd> | Open a project |
| <kbd>⌘</kbd> <kbd>I</kbd> | Import media at the playhead |
| <kbd>⌘</kbd> <kbd>E</kbd> | Export video |

## Playback

| Shortcut | Action |
| --- | --- |
| <kbd>Space</kbd> | Play / stop |
| <kbd>→</kbd> | Next frame |
| <kbd>←</kbd> | Previous frame |

## Arrange

| Shortcut | Action |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move selected clips up / down a track |
| <kbd>⌘</kbd> <kbd>G</kbd> | Group |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>G</kbd> | Ungroup |
| <kbd>Esc</kbd> | Cancel a drag in progress |

## Preview

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>0</kbd> | Fit the preview to the window |
| <kbd>⌘</kbd> <kbd>+</kbd> | Zoom in |
| <kbd>⌘</kbd> <kbd>-</kbd> | Zoom out |

## Mouse and trackpad

| Gesture | Where | Action |
| --- | --- | --- |
| <kbd>Shift</kbd> + click | Timeline | Add a clip to the selection |
| Drag on empty space | Timeline | Select clips inside a box |
| Hold, or <kbd>Option</kbd> + drag | Timeline clip | Move the clip to another track |
| <kbd>Option</kbd> + click | Volume line | Add or remove a volume point |
| Pinch, or <kbd>Ctrl</kbd> + scroll | Timeline or preview | Zoom |
| <kbd>Shift</kbd> + drag a handle | Preview | Lock or free the proportions |
| <kbd>Option</kbd> + drag a keyframe | Curve editor | Move without snapping to the playhead |

## Mask pen

While drawing a mask with the pen:

| Shortcut | Action |
| --- | --- |
| <kbd>Return</kbd> | Close the path |
| <kbd>Delete</kbd> | Remove the last point |
| <kbd>Esc</kbd> | Discard the mask |

## Crop

| Shortcut | Action |
| --- | --- |
| <kbd>Return</kbd> | Apply the crop |
| <kbd>Esc</kbd> | Cancel |

## Caption editor

Inside a caption line in the [Automatic Caption](auto-captions) panel:

| Shortcut | Action |
| --- | --- |
| <kbd>Return</kbd> | Split the line at the cursor |
| <kbd>Delete</kbd> at the start | Join with the line above |
| <kbd>Fn</kbd> <kbd>Delete</kbd> at the end | Join with the next line |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo a split or join |
| <kbd>⌘</kbd> <kbd>Return</kbd> | Start transcribing (in the clip picker) |

## Turning shortcuts off

Click the **padlock** in the preview toolbar (**Lock keyboard shortcuts**) to stop CartCut from reacting to keys. Click it again to turn them back on.
